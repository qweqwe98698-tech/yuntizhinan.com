# 代理协议知识库

了解协议并不是技术人员的专利。订阅里的 SS、VMess、Trojan、Hysteria2 各有取舍，知道它们的差异，你就能看懂机场的套餐介绍，也能在连接异常时多一条排查思路。

## 五篇文章导航

- [Shadowsocks 详解](/protocols/shadowsocks/)：历史最悠久、生态最成熟的加密代理协议，轻量、兼容性好，几乎所有客户端都支持。适合入门理解代理的基本原理。
- [VMess 与 VLESS](/protocols/vmess-vless/)：V2Ray 生态的两代协议，支持 WebSocket、TLS 等多种传输组合，伪装能力更灵活。VLESS 是精简后的新版本，性能开销更低。
- [Trojan 协议](/protocols/trojan/)：把代理流量伪装成正常 HTTPS 访问的思路，特征不明显，配置相对简单。依赖有效的 TLS 证书是它的前提。
- [Hysteria2 协议](/protocols/hysteria2/)：基于 QUIC/UDP 的新一代协议，主打高丢包环境下的速度表现，弱网场景潜力大，但部分网络会限制 UDP 流量。
- [IEPL 与 IPLC 专线](/protocols/iepl-iplc/)：严格说这是线路而非协议——不经公网的跨境专线，延迟低且不受国际出口拥堵影响，通常出现在中高端套餐里。

## 协议与线路是两回事

协议解决「数据怎么加密和伪装」，线路解决「数据走哪条物理路径」。同一个协议既可以跑在普通公网中转上，也可以跑在 IEPL 专线上，体验天差地别；反过来，专线配上任何主流协议都能获得低延迟。看机场宣传时要把两者分开评估：协议决定兼容性与抗封锁能力，线路决定速度与稳定的上限。

## 按需求选协议

日常浏览与看视频，主流协议都能胜任，优先选客户端支持最好的即可；网络环境干扰较多时，Trojan 或带 TLS 伪装的 VLESS 通常更稳；跨运营商高峰丢包明显的场景，可以试试 Hysteria2；对延迟和稳定性有硬性要求（远程办公、实时协作），协议的影响反而次要，应优先考虑走专线的套餐。多数机场会在一个订阅里混合提供多种协议节点，实际使用中逐个测试比纸面参数更可靠。
