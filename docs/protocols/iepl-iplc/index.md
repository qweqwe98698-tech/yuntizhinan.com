# IEPL 与 IPLC 专线是什么：看懂机场宣传里的跨境专线

严格来说，IEPL 和 IPLC 并不是代理协议，而是两种跨境通信线路：IPLC（国际私用出租线路）与 IEPL（国际以太网专线）都是电信运营商面向企业出租的点对点专用链路，两端机房直接相连，不与公众互联网混跑。机场行业借用这类线路承载节点流量，「专线机场」由此得名。它与[各类代理协议](/protocols/)的关系可以概括为：协议是「车」，专线是「路」。

## 工作原理

先看普通节点怎么走。你的流量从家中出发，经国内公网汇聚到国际出口，跨过出口后再经公网到达境外服务器——国际出口是全国流量共用的瓶颈，晚间人人都在看视频、开视频会议时，出口拥塞会直接表现为延迟飙升与丢包，这正是许多用户「白天流畅、晚上卡顿」的主因，相关排查可见[网速慢与丢包问题指南](/troubleshooting/speed/)。

专线则换了一条路：流量先到达机场设在境内的入口服务器，随后进入运营商为租户单独开通的点对点链路，直达境外机房，再由出口服务器转发到目标网站。所谓「不过公网出口」，指的就是中间跨境这一段走的是租用的内部专用通道，不参与公网国际出口的排队，自然也不受出口拥塞的影响。你设备到境内入口的一段仍走国内公网，但这段路程短、质量普遍良好。

至于节点上跑什么，与普通机场并无二致——依旧是 [Shadowsocks](/protocols/shadowsocks/)、[Trojan](/protocols/trojan/) 之类的常规协议，专线改变的只是数据经过的物理路径。

## 主要特点

- **延迟低且波动小**：路径专用、无出口排队，晚高峰与凌晨的延迟曲线差距不大，这是专线区别于公网中转的直观标志。
- **丢包率低**：链路带宽有保障，跨境段丢包通常远低于公网线路。
- **抗干扰性较好**：跨境段不经公网出口，受出口层面波动的影响相对较小。
- **成本高昂**：专线带宽按 Mbps 逐月计费，单位成本数倍于公网带宽。这直接决定了专线套餐价格更高，且普遍采用流量倍率计费来分摊成本。

## 适用与不适用场景

**适合**：视频会议、远程办公等对稳定性敏感的用途（商务用户可参考[办公向机场挑选](/airport/business/)）；晚高峰重度使用者；对延迟敏感的实时应用。

**不适合**：预算有限、以日常浏览为主的轻度用户——公网中转套餐的性价比往往更符合需求，可参考[高性价比机场指南](/airport/cheap/)；另外，把专线当作「隐私升级」来买也是误解，下文误区部分会展开。

## 客户端支持情况

专线是线路层的事，对客户端完全透明：Clash/Mihomo、Shadowrocket、sing-box、v2rayN 都按节点承载的协议正常连接即可，无需任何特殊设置。你在客户端里看到的只是名称带有「IPLC」「IEPL」标签的普通节点，标签本身不影响导入与使用。

## 常见误区

1. **「节点名带专线二字就是专线」**：节点名称可以随意填写，市面上确有把公网中转标成 IPLC 的情况。低价套餐宣称全专线时尤其值得警惕，结合[假机场识别指南](/security/fake-airport/)综合判断更稳妥。
2. **「专线更匿名、更安全」**：专线解决的是拥塞与稳定问题，不改变服务商能看到流量去向的事实，隐私层面与普通节点没有本质区别。
3. **「IEPL 天然强于 IPLC」**：两者只是技术层级不同——IPLC 偏底层电路，IEPL 基于以太网交付——实际体验取决于机场采购的线路质量与超售程度，而非名称本身。
4. **「上了专线就一定快」**：专线改善的是延迟与稳定性，峰值速度仍受套餐带宽与服务商超售情况制约。

## FAQ

**怎么判断买到的是不是真专线？**
最实用的办法是对比时段表现：晚间九到十一点与工作日白天分别测延迟和丢包，真专线两个时段的数据接近，公网线路则高峰期明显劣化。长期口碑也是重要参考，可结合[稳定型机场榜单](/airport/stable/)交叉验证。

**专线套餐为什么按倍率扣流量？**
专线每 GB 的成本是公网的数倍，倍率（如走专线节点消耗两倍流量）是服务商分摊线路成本的通行做法，本身并非套路。

**IPLC 和 CN2 是一回事吗？**
不是。CN2 是中国电信的优质公网骨干，流量仍经公网国际出口，好比「更通畅的公路」；IPLC/IEPL 则是完全独立的「专用轨道」，两者的定价与稳定性都不在一个层级。

**专线节点适合搭配哪种协议？**
没有特殊讲究。专线本身已提供质量保障，常见协议均可胜任，服务商通常会选择开销较小的方案，用户按订阅默认配置使用即可。
