# 海外 AI 工具百科：访问、注册与风控一页说清

本页收录的「AI 工具」指 ChatGPT、Claude、Midjourney 这类由海外公司运营、在大陆无法直接使用的人工智能服务。与[软件百科](/software/)其他分类相比，这类软件的特殊之处在于：能不能打开只是第一关，IP 质量、账号地区与长连接稳定性才真正决定日常体验。下文按清单、注册、网络、故障四个层次展开，可作为这类问题的总入口。

## 软件清单

| 软件名 | 主要用途 | 大陆可访问性 | 账号地区要点 |
| --- | --- | --- | --- |
| ChatGPT | 对话助手、写作与编程辅助 | 需代理 | 大陆手机号不在注册支持之列，服务地区名单以官方页面为准 |
| Claude | 对话助手、长文档处理 | 需代理 | 注册需处于支持地区，名单以官方页面为准 |
| Gemini | Google 系对话与多模态助手 | 需代理 | 依附 Google 账号，账号所在地区影响可用功能 |
| Perplexity | AI 搜索与资料整理 | 需代理 | 邮箱即可注册，付费方案的支付方式有地区差异 |
| Grok | xAI 对话助手 | 需代理 | 可关联 X 账号使用，可用地区以官方说明为准 |
| Poe | 多模型聚合对话平台 | 需代理 | 支持邮箱或第三方账号登录 |
| Midjourney | AI 图像生成 | 需代理 | 依赖 Discord 或官网账号，订阅需海外支付方式 |
| Hugging Face | 模型托管与下载、在线演示 | 需代理 | 邮箱注册即可，下载大模型文件对线路带宽要求高 |
| Replicate | 云端模型推理与 API 调用 | 需代理 | 常用 GitHub 账号登录，计费需绑定海外支付方式 |

## 账号注册与地区问题

先分清两个概念：**网络可达**指设备能连上服务器，**账号地区支持**指服务商允许该地区的用户注册和付费。AI 工具的大量问题出在第二层——网络通了，账号侧仍可能被拦下。常见的坑有四类：

- **手机号**：ChatGPT、Claude 等注册时往往要求手机验证，大陆号码通常不在支持列表内，具体以注册页面提示为准。收不到验证码时，先按[短信验证码收不到的排查](/troubleshooting/verification/sms-not-received/)判断是平台不支持该号段，还是短信被拦截。
- **支付方式**：订阅制 AI 服务普遍要求账号地区对应的信用卡或第三方支付，大陆发行的卡能否使用因平台而异，以支付页面实际提示为准。不要轻信来路不明的「代充」渠道，相关风险见[账号安全建议](/security/account-safety/)。
- **应用商店地区**：ChatGPT、Gemini 等官方 App 未在大陆区商店上架，iOS 用户需要切换到已上架地区的 Apple ID 才能下载安装。
- **信息一致性**：注册时的 IP 地区、账单地址与日常登录地区差异过大，可能触发额外审核，注册后尽量保持出口地区固定。

## 需要什么网络环境

这类软件对网络的要求可以概括为「三看」。

**一看 IP 质量。** AI 服务商普遍部署了严格的风控与人机验证，被大量用户共享、已被标记为数据中心来源的出口 IP，容易遇到反复验证、注册受阻甚至拒绝服务。挑选通道时，IP 质量的权重高于峰值速度，具体标准见 [AI 工具场景的机场选择](/airport/ai/)。

**二看长连接稳定性。** 对话回答是逐字流式输出的，底层依赖 SSE 或 WebSocket 长连接；线路频繁抖动，或中间设备提前掐断连接，回答就会停在半截。这类问题的判断方法见 [ChatGPT 输出中断排查](/troubleshooting/websocket/chatgpt-stream/)。

**三看使用形态。** 网页版的压力集中在浏览器侧，IP 风控、人机验证、长连接都要过；通过 API 把模型接入自己的程序时，则更考验出口 IP 所在地区是否被服务商支持、超时与重试策略是否合理。两种形态可以配置不同的分流策略，开发场景还可参考[开发者软件分类](/software/developer/)。

## 常见故障与排查入口

- **提示「服务在当前地区不可用」**：多半是出口节点所在地区不在支持名单内，换一个支持地区的节点即可验证；仍无效再查账号注册地区，基础排查见[故障排查中心](/troubleshooting/)。
- **回答输出到一半停住**：典型的长连接被切断，按 [ChatGPT 流式输出排查](/troubleshooting/websocket/chatgpt-stream/)逐步定位是节点问题还是客户端设置问题。
- **反复弹出人机验证**：通常指向 IP 已被标记，优先换出口而不是反复答题；由此引发的登录连锁问题见[登录问题排查](/troubleshooting/login/)。
- **注册收不到验证码**：先确认号码所属地区是否被平台支持，再按[验证码排查](/troubleshooting/verification/sms-not-received/)处理拦截与频控问题。
- **页面完全打不开**：属于基础连通性问题，与 AI 服务本身无关，从[连接超时排查](/troubleshooting/timeout/)入手。

## FAQ

**问：挂了代理仍提示地区不可用，是账号出问题了吗？**
不一定。先确认当前出口节点的地区在服务商支持名单内，再排除 DNS 泄漏暴露真实位置的可能；两者都正常仍被拒绝，才需要检查账号本身的状态。

**问：网页版和 API 用同一条线路可以吗？**
可以用，但不一定合适。网页版看重 IP 质量与长连接稳定，API 更看重可达性与固定出口，两者需求冲突时，分开配置分流规则更稳妥。

**问：Hugging Face 下载模型很慢怎么办？**
大文件下载考验的是带宽与丢包率而非 IP 质量，可换大带宽节点重试；持续中断可按[丢包诊断](/troubleshooting/speed/packet-loss-diagnosis/)确认瓶颈位置。

**问：该用哪家服务商的节点？**
