# 办公与协作软件指南：页面开了，字体和图片却不显示？

办公协作类软件指文档、设计、项目管理、网盘与视频会议这些团队日常依赖的境外服务。它们大多没有被完全屏蔽，麻烦集中在「半通不通」：主站能开，静态资源加载失败；文字消息正常，语音会议卡成幻灯片。本页按这个特点整理十款常用工具的访问要点与排查方向。

## 软件清单

| 软件名 | 主要用途 | 大陆可访问性 | 账号地区要点 |
| --- | --- | --- | --- |
| Dropbox | 文件同步与网盘 | 需代理 | 邮箱注册，不限地区 |
| Google Workspace | 邮箱、文档与云端硬盘 | 需代理 | 依赖 Google 账号，企业版由管理员分配 |
| Slack | 团队即时通讯 | 部分功能受限（文件与图片加载常失败） | 邮箱注册，企业工作区多绑定 SSO 登录 |
| Notion | 文档与知识库 | 部分功能受限（页面可开，图片等资源加载不稳定） | 支持邮箱与 Google、Apple 账号登录 |
| Figma | 界面设计协作 | 部分功能受限（资源加载与实时协作不稳定） | 邮箱注册，团队席位由管理员分配 |
| Canva | 平面设计与模板 | 可直连（国际版部分资源受限，另有独立的中国版） | 国际版与中国版账号体系分离 |
| Airtable | 表格数据库 | 部分功能受限 | 邮箱注册 |
| ClickUp | 项目与任务管理 | 部分功能受限 | 邮箱注册 |
| Asana | 项目协作 | 部分功能受限 | 邮箱注册，常配合企业域名使用 |
| Zoom | 视频会议 | 可直连（跨境会议质量随线路波动） | 入会通常无需账号，注册与付费政策以官方页面为准 |

## 账号注册与地区问题

办公类工具的注册门槛不高，多数邮箱即可，真正的地区问题藏在两个地方。一是账号体系分叉：Canva 等产品在中国市场有独立版本或本地合作模式，国际版与本地版的账号、模板、数据互不相通，团队协作前应先确认成员在同一个体系里。二是 SSO 依赖：不少企业把 Slack、Figma、Asana 的登录绑定在 Google Workspace 上，代理没配好时会卡在跳转环节——表面是协作工具登录失败，根源是 Google 服务不可达，这类问题可对照 [Google 软件分类](/software/google/)处理。

## 需要什么网络环境

办公场景的三类流量，对网络的要求截然不同。

**静态资源加载**。Notion、Figma、Slack 的页面本体与图片、字体、头像往往分布在不同的 CDN 域名上，分流规则只放行主域名时，就会出现「页面开了但图全挂」的典型症状。遇到这种情况，优先查看代理软件的连接日志，确认哪些资源域名被放去了直连。

**视频会议**。Zoom 与 Slack 通话对丢包和抖动高度敏感——带宽再大，持续丢包也会让声音断续、画面冻结。跨境会议多的团队，选线时应把线路质量放在带宽数字前面，一般性标准见[稳定性优先的机场怎么选](/airport/stable/)。

**大文件同步**。Dropbox、Google Drive 的同步客户端需要长时间保持连接，频繁断流会反复触发重传，看重的是持续吞吐。还要注意同步客户端属于后台进程，需确认它确实被代理接管，macOS 用户可参考 [Mihomo Party 教程](/tutorials/macos/mihomo-party/)检查接管方式。

团队整体的网络方案，包括多人共用与按岗位分流的思路，见[跨境办公场景的机场推荐](/airport/business/)。

## 常见故障与排查入口

- **文档能开、图片字体不显示**：多为 CDN 域名未走代理，先检查分流规则；仍无头绪时从[故障排查中心](/troubleshooting/)按症状进入。
- **会议中反复卡顿掉线**：按[丢包诊断方法](/troubleshooting/speed/packet-loss-diagnosis/)确认丢包发生在哪一段，再决定换节点还是换线路。
- **网盘同步停在某个百分比不动**：典型的长连接中断，参考[超时类故障](/troubleshooting/timeout/)。
- **SSO 登录跳转后白屏**：登录链路跨多个域名，任一环节不通都会中断，见[登录类故障](/troubleshooting/login/)。
- **打开速度时快时慢、偶发解析异常**：可能与 DNS 有关，按 [DNS 类故障](/troubleshooting/dns/)的流程检测。

## FAQ

**为什么文字聊天正常，语音一开就卡？**
文字消息是小数据量的短请求，对丢包不敏感；语音是实时流，丢包与抖动会直接转化为卡顿。两者对网络的要求不在一个量级，文字正常不能说明线路适合开会。

**公司没有统一方案，个人先用代理开会合适吗？**
技术上可行，但企业数据经个人代理传输有合规与安全的双重考量，建议先了解[无日志与隐私保护的基本概念](/security/no-log-privacy/)，涉及敏感数据时推动团队采用统一方案。

**Zoom 标注可直连，还需要代理吗？**
入会本身通常可以直连，但跨境会议的质量随线路状况波动，直连不佳时经优质节点反而更稳。是否使用以实际体验为准，不必一刀切。

**大文件同步很慢，是代理的问题吗？**
不一定。先直连测一次上传下载作基线，再开代理对比。若两者都慢，瓶颈可能在本地宽带的上行；只有代理明显更慢时，才值得换节点或调整分流。
