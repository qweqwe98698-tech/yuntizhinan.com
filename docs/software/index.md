# 海外软件百科：八大分类速查

许多海外软件的问题并不是「打不开」这么简单——有的限制注册地区，有的检测网络环境，有的仅在特定国家上架。软件百科把常用的境外服务按用途分成八类，每个词条固定回答四件事：这是什么、有哪些地区限制、对网络有什么要求、常见错误如何处理。

## 八大分类导航

### AI 工具

代表软件：ChatGPT、Claude、Gemini、Midjourney。常见问题集中在「服务在当前地区不可用」、账号风控与对话输出中断。词条见 [AI 软件分类](/software/ai/)，网络通道的选择思路见 [AI 工具场景推荐](/airport/ai/)。

### Google 系

代表软件：Gmail、YouTube、Google Play、Google Scholar。典型问题是登录时反复要求验证、Play 商店地区不符、部分服务白屏。词条见 [Google 软件分类](/software/google/)，对应场景参考 [Google 服务的网络选择](/airport/google/)。

### 海外社交

代表软件：Telegram、X、Instagram、WhatsApp、Discord。高频问题是注册时收不到短信验证码、消息发不出去、语音通话质量差。词条见[海外社交软件分类](/software/social/)，通道选择见[社交平台场景推荐](/airport/social/)。

### 流媒体

代表软件：Netflix、Disney+、Spotify、YouTube Premium。常见问题是提示检测到代理、不同地区片库差异、会员定价区域限制。词条见[流媒体软件分类](/software/streaming/)，解锁相关的通道要求见[流媒体解锁场景](/airport/streaming/)。

### 开发者工具

代表软件：GitHub、Docker Hub、npm、Hugging Face。典型问题是克隆和拉取缓慢、镜像下载超时、包管理器无法访问源。词条见[开发者软件分类](/software/developer/)，参考[开发者场景的网络方案](/airport/developer/)。

### 办公协作

代表软件：Zoom、Slack、Notion、Google Workspace。常见问题是会议卡顿掉线、文档同步失败、企业账号登录受限。词条见[办公软件分类](/software/office/)，团队使用可参考[跨境办公场景](/airport/business/)。

### 游戏平台

代表软件：Steam、Epic Games、PSN、任天堂 eShop。高频问题是商店区域与账号不符、联机延迟高、下载速度慢。词条见[游戏软件分类](/software/gaming/)，加速思路见[游戏加速场景](/airport/gaming/)。

### 跨境电商

代表软件：亚马逊卖家平台、eBay、Shopify、PayPal。这一类对网络环境最敏感，常见问题是账号关联风险、支付风控、店铺后台访问异常。词条见[跨境电商软件分类](/software/ecommerce/)，网络隔离与合规注意事项同样参考[跨境办公场景](/airport/business/)。
