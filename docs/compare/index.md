# 机场横向对比方法论

把多家服务放进同一张表之前，先要明确比什么、怎么比。脱离维度定义的对比表只是营销素材。本页公开云梯指南做横向对比时采用的九个维度，以及阅读对比表时应有的判断方式。

## 九个对比维度

1. **价格与套餐**：折算到每月每 GB 的实际成本，注意流量重置规则与超量计费方式。
2. **节点地区**：覆盖的国家数量只是表象，更重要的是你常用地区的节点数量与质量。
3. **线路类型**：公网中转与专线的体验差距很大，线路类型的辨别方法见 [IEPL 与 IPLC 专线解析](/protocols/iepl-iplc/)。
4. **晚高峰稳定性**：白天测速普遍好看，工作日 20 点到 23 点的表现才能区分服务档次。
5. **AI 与流媒体表现**：ChatGPT 可用性、Netflix 等平台的解锁地区与稳定程度，需逐项实测。
6. **客户端兼容**：是否提供 Clash、Shadowrocket 等主流格式订阅，配置说明是否完善。
7. **设备数限制**：同时在线设备上限，多设备家庭与单人使用的需求差别明显。
8. **客服与售后**：工单响应速度、退款政策是否真实可执行。
9. **运营时长与风险**：运营历史、价格策略是否激进，参考[跑路与虚假宣传的识别方法](/security/fake-airport/)。

## 如何读对比表

对比表不存在「总分第一」的客观答案：维度权重取决于你的用途——游戏玩家应放大延迟权重，追剧用户应放大解锁权重。阅读时注意三点：确认数据的测试时间（网络质量随时间波动）；警惕只有结论没有测试条件的表格；把「未测试」与「测试未通过」区分开，前者不代表负面。
