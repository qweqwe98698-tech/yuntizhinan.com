# 安全与避坑指南

这个行业门槛低、缺乏监管，踩坑并不罕见：订阅被盗用、隐私被记录、商家收钱后消失，都是真实发生过的风险类型。本栏目把常见风险分成三类，每类给出识别方法与应对措施。

## 三类常见风险

### 账号与订阅泄露

订阅链接就是你的使用凭证，泄露后他人可以直接消耗你的流量，甚至借你的账号做违规行为。共享订阅、在公开场合粘贴链接、使用来路不明的「免费节点」都是高发场景。防护要点见[账号与订阅安全](/security/account-safety/)。

### 隐私与日志

代理服务商在技术上有能力看到你的连接元数据，「无日志」承诺是否可信、如何最大限度降低暴露面，需要一套判断框架。详细分析见[无日志与隐私保护](/security/no-log-privacy/)。

### 跑路与虚假宣传

低价年付促销后关站跑路、夸大线路与解锁能力、伪造用户评价，是最常见的三种套路。识别这类商家的特征清单见[虚假机场与跑路预警](/security/fake-airport/)。

## 通用避坑原则

- **短周期购买**：优先月付或季付，用小成本验证服务质量，年付只考虑运营时间长、口碑经过时间检验的商家——即便如此也没有绝对保障。
- **备用方案**：至少保留一个备用服务或备用节点来源，任何单一商家都可能出现故障或停业。
- **警惕绝对化宣传**：「永不跑路」「100% 解锁」「绝对稳定」这类表述本身就是危险信号，负责任的商家不会做这种承诺。
- **付款留痕**：保留订单与沟通记录，出现纠纷时至少有申诉依据。
