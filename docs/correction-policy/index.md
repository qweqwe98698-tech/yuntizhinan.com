# 内容纠错与修正机制

错误不可避免——境外网络服务的价格、政策和客户端界面变化极快，再勤快的编辑部也追不上所有变动。我们能做的是：欢迎指错、快速核实、公开修正。这就是本页存在的意义。

## 欢迎反馈的错误类型

以下任何一类问题，都值得告诉我们：

- **价格过期**：套餐价格、优惠信息与官网不符；
- **政策变化**：服务商的退款规则、设备数限制等条款已调整；
- **教程步骤失效**：[客户端教程](/tutorials/)中的界面截图或操作步骤与当前版本对不上；
- **测试数据过期**：评测中的测速、解锁结论与当前实际情况明显不符；
- **事实错误**：任何页面中的描述性错误，包括软件功能、协议特性等知识性内容。

## 处理流程

收到反馈后，我们按以下步骤处理：

1. **核实**——由编辑部按[测试方法](/about/methodology/)或权威来源验证反馈是否属实，不凭单一反馈直接改动结论；
2. **修正**——确认有误后修改内容，涉及测试数据的安排复测；
3. **更新时间**——修正完成后同步更新页面的「更新于」时间；
4. **修正记录**——影响结论的重大错误，会在文内注明修正记录，说明改了什么、为什么改，不做无痕修改。

## 主动复测承诺

纠错不能只依赖读者。对时效性强的内容——机场评测数据、价格信息、[故障排查](/troubleshooting/)方案——我们按周期主动复测与核对，不等到出错才更新。复测周期与数据时效的具体规则，见[编辑政策](/editorial-policy/)中的更新与下线机制。

读者的每一条指错，都会让下一位访客少踩一个坑。感谢你花时间反馈。
