# 稳定机场怎么选：把「稳定」拆成可以测量的指标

## 从一次卡顿的会议说起

晚上九点，跨国视频会议进行到一半，画面定格、声音断续——这是依赖代理办公、上课的用户最怕的场景。对这类用户来说，「稳定」不该是宣传页上的形容词，而应是一组可以亲手测量的数字。这份指南把稳定性拆成若干可测指标，帮你在试用期内就判断一家机场值不值得长期付费。其他用途的挑选入口见[机场总览](/airport/)。

## 稳定性的六个可测指标

1. **晚高峰速率保持率**：分别在工作日下午与 21:00–23:00 测同一节点，用晚高峰速率除以闲时速率。跨境带宽在晚间普遍收紧，保持率越高说明商家带宽冗余越足。
2. **丢包率**：对代理服务器持续 ping 十分钟以上观察丢包。持续高丢包会造成网页反复加载、通话卡顿，测量与判读方法见[丢包诊断教程](/troubleshooting/speed/packet-loss-diagnosis/)。
3. **断线重连时间**：人为断开 Wi-Fi 再恢复，记录客户端恢复可用的秒数；同时观察一天内非人为断连的次数。
4. **WebSocket 长连接存活**：网页版 AI 对话、在线文档协作依赖长连接，挂起页面半小时看会话是否被中断。
5. **线路类型**：IEPL/IPLC 专线不经公网，晚高峰波动通常小于公网中转，但成本高得多，原理与鉴别方法见[专线协议详解](/protocols/iepl-iplc/)。宣称全专线却卖超低价的商家要警惕。
6. **故障切换能力**：同地区是否有多个可互替节点，单点故障时能否快速手动或自动切换。

## 测试机制与当前进度

以上指标正是本站[评测方法论](/about/methodology/)中稳定性部分的测试项：每个候选品牌连续七天、每天三个时段记录速率与丢包。候选品牌正在按此流程逐一实测，实测完成前榜单区只显示「待实测」徽章，本页不对任何品牌给出稳定性结论。

## 套餐与价格怎么看

稳定性优先的用户，预算应向线路质量倾斜而非流量规模：同价位下，选流量少但走专线或优质中转的套餐，通常好过流量翻倍的公网直连套餐。做法是先月付买入，跑完上面的测试项再决定是否转年付。远程办公用户还可以结合[跨境办公场景](/airport/business/)的多设备与合规需求一并规划。

## 常见问题

**专线一定比中转稳吗？** 通常波动更小，但商家超售同样会拖垮专线，实测数据比线路名词可靠。

**测几天才能下结论？** 至少覆盖一个完整工作周的晚高峰；只测一晚容易被偶然因素误导。

**白天流畅晚上很卡，正常吗？** 一定程度的晚高峰衰减普遍存在，但速率保持率过低说明超售严重，这正是需要量化对比的原因。

**客户端显示已连接却上不了网？** 多为规则或 DNS 配置问题而非线路故障，按 [Clash 连接异常排查](/troubleshooting/timeout/clash-no-network/)处理。

**换协议能提升稳定性吗？** 有时能。不同协议对网络波动的抗性不同，前提是商家节点支持；整体速度问题可先从[测速与卡顿排查](/troubleshooting/speed/)入手定位。

## 风险提示

「绝对稳定」「永不掉线」本身就是危险信号——跨境网络受多重因素影响，任何商家都做不到零波动。把这类绝对化宣传当作筛除条件之一，更多识别特征见[虚假机场识别指南](/security/fake-airport/)。
