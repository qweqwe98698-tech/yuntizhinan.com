# 挑游戏线路：把测速软件先放到一边

一条能跑出 500 Mbps 的线路，联机体验可能不如另一条只有 50 Mbps 但延迟平稳的线路——这是游戏场景最需要先建立的认知。联机对战每秒只交换很小的数据包，带宽几乎从来不是瓶颈；决定手感的是三条曲线：延迟（ping 值高低）、抖动（延迟是否忽高忽低）、丢包（数据包是否丢失重传）。抖动尤其隐蔽：平均 60ms 但在 40–120ms 之间跳动的线路，实际体验往往差于稳定的 80ms。这套标准与[机场总览](/airport/)介绍的通用维度差别最大，值得单独展开。

## 挑线路看什么：六项硬指标

1. **物理路径合理性**：延迟下限由光缆距离决定，去日服选日本或临近节点，绕行美国的「日本节点」延迟不可能好看。
2. **抖动幅度**：连续 ping 数分钟观察波动区间，比单次 ping 值更能说明问题。
3. **丢包率**：偶发丢包在游戏里会被直接感知为回弹与瞬移，持续高于 1–2% 就应更换线路，自查方法见[丢包问题诊断步骤](/troubleshooting/speed/packet-loss-diagnosis/)。
4. **UDP 转发支持**：多数联机游戏走 UDP 协议，而部分机场只做 TCP 转发或对 UDP 限速，购买前必须确认。基于 UDP 的传输协议在这类场景有天然优势，原理可读 [Hysteria2 协议详解](/protocols/hysteria2/)。
5. **晚高峰表现**：游戏时段与网络拥堵时段高度重合，闲时数据没有参考意义。
6. **分流可配置性**：理想做法是游戏本体与 Discord 语音、平台下载分开处理——语音和商店走代理，对战流量按实际情况选择直连或低延迟节点，各平台的连接需求可对照[游戏平台与工具访问指南](/software/gaming/)。

## 价格之外先看这些

游戏用户流量消耗普遍不大，比价时别被「大流量」话术带偏，优先确认：宣传低延迟的专线节点是否在你考虑的套餐档位内、是否按高倍率扣流量；能否月付试玩一个赛季再续；退款与换套餐政策是否清晰。流量包大小在这个场景里几乎是最不重要的参数。

## 常见疑问

**游戏加速器和机场应该选哪个？**
专业加速器只优化游戏流量、通常延迟表现更专注；机场胜在通用性，能同时覆盖浏览、语音与下载。两者不冲突，不少玩家是组合使用。

**为什么 ping 值不高，打起来还是卡？**
大概率是抖动或丢包，平均延迟正常但波动大同样毁手感。按上文丢包诊断步骤逐段排查即可定位。

**Discord 语音需要什么样的节点？**
语音对延迟的容忍度高于对战流量，但要求连接持续稳定。把语音单独分流到稳定节点，与游戏流量互不挤占，是更稳妥的配置。

**主机（PS/Xbox/Switch）能用机场吗？**
主机通常无法直接安装客户端，常见做法是通过路由器接管流量，配置门槛较高，可参考 [OpenWrt 路由器教程](/tutorials/router/openwrt/)。

**看直播和下载游戏也用同一个节点吗？**
不建议。下载吃带宽、对战吃低延迟，两者混在一个节点会互相拖累；顺带一提，若还有追剧需求，选择逻辑又不一样，见[流媒体场景的机场选择](/airport/streaming/)。

## 防坑提醒

「电竞专线」「零延迟」是这个场景的高频营销词，而延迟受物理距离约束，任何服务都不可能突破。对宣传远超合理范围的商家，先对照[虚假机场的识别方法](/security/fake-airport/)核验，再用月付小额试错，确认晚高峰表现后再谈长期套餐。
