# 给 iPhone 用户的机场挑选指南：围绕小火箭的三个现实约束

在 iOS 上做代理，绕不开三个平台层面的现实约束。其一，Shadowrocket（小火箭）是付费应用且未在中国区 App Store 上架，需要外区 Apple ID 才能购买下载；其二，iOS 对 VPN 类扩展有严格的内存限制，节点数量过于庞大的订阅可能导致启动失败或闪退；其三，手机在 Wi-Fi 与蜂窝网络之间频繁切换，代理连接要经得起反复重连。这三条约束共同决定了：适合小火箭用户的机场，和桌面场景的选择标准并不一样——通用维度请先读[机场总览](/airport/)，本页只谈 iOS 特有的部分。

## iOS 场景的特殊前提

先把准备工作理清：外区 Apple ID 与应用购买属于一次性成本，配置流程可按 [Shadowrocket 配置教程](/tutorials/iphone/shadowrocket/)完成；真正长期影响体验的是订阅质量。小火箭支持 Shadowsocks、VMess、Trojan、Hysteria2 等主流协议，理论上大多数机场都能用，但「能用」与「好用」之间隔着导入便利性、节点规模控制、移动网络适应性这几道坎。

## 选择标准：六个 iOS 专属指标

1. **一键导入支持**：商家是否提供小火箭专用的一键导入链接或二维码，免去手动复制粘贴与格式选择。
2. **订阅节点规模适中**：动辄数百节点的订阅在 iOS 上是负担而非福利，理想的商家会提供精简订阅或按地区筛选的选项。
3. **网络切换后的重连速度**：从 Wi-Fi 走到蜂窝网络，连接恢复要快且不需要手动干预；若蜂窝网络下始终连不上，先按 [iOS 蜂窝网络排查步骤](/troubleshooting/mobile-data/ios-cellular/)自查再归因于机场。
4. **协议与小火箭的匹配度**：确认商家下发的节点类型均在小火箭支持范围内，避免订阅里一半节点不可用。
5. **移动端流量友好度**：手机场景流量有限，留意视频类流量的倍率规则与流量提醒机制。
6. **文档与售后**：官网是否有针对 iOS 的接入说明，出问题时能否快速响应。

如果你同时有电脑端的规则分流需求，两端选择标准的差异可对照 [Clash 用户的机场选择](/airport/clash/)；常在手机上看剧的用户，还应结合[流媒体场景的机场选择](/airport/streaming/)一起判断。

## 套餐与价格

手机为主的用户流量消耗通常不大，选套餐优先看小流量档位的单价是否合理，而非大流量套餐的「性价比」。另外确认两点：设备数限制是否允许 iPhone 与 iPad 同时在线；套餐是否区分节点倍率——移动端刷视频叠加高倍率节点，流量消耗会远超预期。

## 常见问题

**没有外区 Apple ID 能用小火箭吗？**
不能直接下载。需要注册或借助外区账号购买，属于使用小火箭的前置成本；请通过正规渠道操作，避免购买来路不明的共享账号带来的安全风险。

**买一次小火箭能在几台设备上用？**
同一 Apple ID 下载的应用可在自己的多台 iOS 设备安装，但代理服务的同时在线设备数以机场套餐规则为准，两者是独立的限制。

**为什么 Wi-Fi 正常，出门用流量就断连？**
先区分是系统网络权限、运营商网络还是节点问题，按上文提到的蜂窝网络排查步骤逐项确认；若多个节点在蜂窝网络下均不可用，再联系商家。

**小火箭和 Clash 客户端选哪个？**
iOS 上小火箭的易用性与协议覆盖对多数人足够；偏好复杂规则分流的用户可以两端并用——手机小火箭、电脑 Clash，多数机场的订阅可同时适配。

## 风险提示

iOS 用户的订阅多通过链接与二维码流转，谨防以「免费共享订阅」为饵的钓鱼配置——导入陌生订阅等于把流量交给陌生人。购买前请对照[虚假机场的识别方法](/security/fake-airport/)核验商家，并只从官网获取订阅链接，泄露后及时重置。
