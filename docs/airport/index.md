# 机场推荐总览：按用途与预算找到合适的服务

在中文网络语境里，「机场」指提供代理订阅服务的商家：付费后获得一条订阅链接，导入 Clash、Shadowrocket 等客户端即可使用多国节点，访问 ChatGPT、Google、Netflix 等境外服务。服务质量因商家而异，选错的代价可能是速度慢、频繁断连，甚至商家跑路。这一页帮你先理清「怎么选」，再进入具体场景。

## 如何选择：四个维度

- **预算**：月付从几元到几十元不等。预算有限可以从[低价套餐的选择思路](/airport/cheap/)入手，但要清楚低价通常意味着更拥挤的共享带宽。
- **稳定性**：如果你依赖代理办公或上课，晚高峰表现和线路类型比价格更重要，参考[稳定性优先的挑选方法](/airport/stable/)。
- **用途**：不同服务的网络要求差别很大——AI 工具看重 IP 纯净度，流媒体看重解锁地区，游戏看重延迟。按用途对号入座能少走弯路。
- **客户端**：确认商家支持你所用客户端的订阅格式，具体配置方法见[客户端教程](/tutorials/)。

## 十二类场景入口

**按需求强度**

- [综合推荐榜单](/airport/recommend/)：不确定自己属于哪类用户时的起点，兼顾速度、稳定与价格的均衡选择。
- [稳定性优先](/airport/stable/)：面向远程办公、网课等对断线容忍度低的场景，重点考察晚高峰与线路类型。
- [便宜机场怎么选](/airport/cheap/)：预算敏感用户的参考，说明低价套餐常见的妥协点与不能让步的底线。

**按目标服务**

- [AI 工具场景](/airport/ai/)：ChatGPT、Claude 等服务对 IP 质量与风控敏感，选择时要关注落地 IP 的纯净度。
- [Google 服务场景](/airport/google/)：围绕 Gmail、Play 商店的登录验证与访问问题，整理选择要点。
- [海外社交场景](/airport/social/)：Telegram、X、Instagram 等平台的连接需求与注册注意事项。
- [流媒体解锁场景](/airport/streaming/)：Netflix、Disney+ 对代理检测较严格，解锁能力需要逐地区确认。
- [开发者场景](/airport/developer/)：GitHub、Docker、npm 等拉取加速，对协议兼容性与长连接稳定性要求高。
- [游戏加速场景](/airport/gaming/)：联机游戏在意延迟与丢包，评价标准与网页浏览完全不同。
- [跨境办公场景](/airport/business/)：多设备、团队使用与合规敏感环境下的选择框架。

**按客户端**

- [适配 Clash 的服务](/airport/clash/)：关注订阅格式与规则分流的支持情况。
- [适配 Shadowrocket 的服务](/airport/shadowrocket/)：iOS 用户需要确认的订阅兼容性与配置要点。

## 本站的推荐机制

云梯指南是独立第三方站点，不接受品牌付费排名。所有进入推荐位的候选品牌，都必须先走完[评测方法论](/about/methodology/)规定的实测流程：真实付费购买、多时段测速、解锁与风控验证。实测尚未完成的品牌会明确标注「待实测」，我们不会在实测前给出任何速度、解锁或稳定性结论。已发布的[评测报告](/reviews/)与各推荐页会随复测结果持续更新；如对内容有疑问，可查阅[更正政策](/correction-policy/)了解反馈处理方式。
