# Telegram、WhatsApp 收不到验证短信的原因与替代办法

短信超过几分钟没到，先别再点发送——密集请求只会拉长冷却时间。等页面倒计时走完，改用语音来电验证；对 +86 号码来说，语音通道的到达情况往往更好。

## 故障表现

- 注册页停在「短信已发出」，倒计时结束仍未收到；
- 多次重发后冷却时间越来越长，甚至提示稍后再试；
- Telegram 老号重新登录时短信迟迟不来——验证码其实已发到旧设备的会话里；
- 也有一种情况是点击发送后页面毫无反馈，请求本身没能发出去。

邮件、App 内渠道的验证码问题另见[验证码问题总览](/troubleshooting/verification/)。

## 最常见原因

1. **+86 号码的客观限制**。验证短信由海外网关经国际通道下发，链路长、环节多，途中可能被运营商的垃圾短信策略拦截或明显延迟；不同服务、不同时段的到达情况差异较大。
2. **验证码没走短信**。Telegram 对已注册过的号码，会优先把验证码发到当前已登录的客户端，短信要等一段时间后才作为备选提供。
3. **虚拟号与接码号**。网络虚拟号码的号段容易被识别，可能直接拒发；用接码平台注册的账号即便成功，后续封禁风险也高。
4. **请求过于频繁**。短时间反复触发发送会被限流，冷却从几十秒逐步拉长到数小时。
5. **手机侧拦截**。骚扰拦截应用、运营商拦截服务，或双卡设置指向了另一张卡。

## 快速判断方法

- 翻手机的拦截记录和骚扰过滤归档，双卡用户确认号码对应的卡槽在正常接收；
- Telegram 用户检查其他已登录设备（包括桌面端）的「Telegram 服务通知」会话；
- 观察点击发送后的页面反应：立刻进入倒计时说明请求已送达，只是下发受阻；毫无反应则先解决网络问题；
- 等待冷却结束，看页面是否出现语音验证选项。

## 分应用解决步骤

### Telegram

1. 老号先找旧设备或桌面端，验证码大概率已在服务通知里；
2. 短信等不到时选择电话呼叫验证，接听来电听取数字验证码；
3. 注册请求要经代理送达服务器，节点不稳时整个流程都会卡住；社交类应用的网络配置建议见[社交软件指南](/software/social/)。

### WhatsApp

1. 验证前建议用 TUN/VPN 模式让全部流量进入代理，避免应用的部分请求直连失败；
2. 短信超时后页面会出现语音验证入口，接听电话获取验证码；
3. 提示「无法验证」或注册后异常退出，多与出口 IP 环境有关，换节点后重走流程。

### 重试节奏与封禁风险

- 两次请求之间拉开间隔，冷却期内不要用第三方工具或反复卸载重装来「刷」验证码；
- 注册环节频繁更换出口 IP、注册成功后立即大量加群或群发，都容易触发新号风控；
- 收得到验证码但注册屡次失败的，放缓节奏、固定节点；账号建立后先正常使用一段时间，两步验证等加固手段见[账号安全防护](/security/account-safety/)。

## 如何判断是不是机场线路的问题

短信下发发生在服务商与运营商之间，代理真正影响的是两步：发送请求能否抵达、提交验证码后能否通过。区分方法：点发送一直转圈、不出倒计时——节点连通性问题，换节点立见分晓；验证码输入正确却被拒——出口 IP 信誉问题，同样换节点验证。多个地区节点都导致注册失败，而别人的网络环境一次通过，可以考虑[社交场景表现更好的机场](/airport/social/)。

## FAQ

**语音验证一直没打过来怎么办？**

语音呼叫也依赖国际线路，偶有失败。确认手机没开陌生来电拦截、放行境外来电显示的号段，间隔一段时间后再触发一次。

**用接码平台的号码注册可以吗？**

不建议。此类号段被识别的概率高，即使注册成功，账号与号码的绑定关系脆弱，找回困难且封禁风险高；长期使用还是绑定自己的真实号码更稳妥。

**收不到验证码和封号有关系吗？**

两者独立但相关：收不到码本身不会封号，但为了收码而高频重试、频繁换 IP 的行为模式，会抬高服务方的风控评分，间接增加受限风险。

**注册成功后还要注意什么？**

尽快设置两步验证密码，登录环境尽量固定，避免频繁在不同地区节点之间切换；登录相关的其他问题见[登录失败排查](/troubleshooting/login/)。
