# 登录失败先分清对象：机场面板还是海外软件账号

同样是登不上，两类问题的解法完全不同：机场官网打不开，多半是主域名被墙，找到备用域名基本能解决；ChatGPT、Google 这类账号登录被拒，则先换一个干净些的节点重试。

## 故障表现

**机场官网一侧**：浏览器打开官网一直转圈、提示连接被重置，或能打开但输入账号密码后报错；客户端里的节点可能仍在正常工作。

**海外软件一侧**：密码正确却被要求反复安全验证、验证码图片刷不出来，或登录后被立即踢出、提示地区异常。

两类症状都不符的，可回[故障排查中心](/troubleshooting/)按症状重新定位。

## 最常见原因

### 机场官网登录失败

1. **主域名被墙**：面板域名被封锁后直连无法访问，而订阅和节点常常还能继续用一段时间，于是出现「能上网、进不了官网」的组合；
2. **密码或邮箱记错**：多数面板以邮箱为账号，换过邮箱或多账号混用时容易输错；
3. **面板维护或迁移**：更换域名、升级面板期间会短暂无法登录，通常伴随公告。

### 海外软件账号登录失败

1. **出口 IP 风控**：机场节点为多人共享，同一 IP 上的登录行为密集，服务方可能要求额外验证甚至暂时拒绝；
2. **验证码加载失败**：reCAPTCHA、hCaptcha 的资源域名若没走代理或被插件拦截，页面只剩一片空白，流程卡在人机验证这一步；
3. **地区频繁跳变**：今天美国节点、明天欧洲节点，登录地忽东忽西，容易触发安全机制要求二次确认。

## 快速判断方法

1. 关闭代理直连打开机场官网，再开代理试一次：直连打不开、走代理能打开，基本可判定域名被墙；
2. 海外软件先看报错文案：提示「密码错误」查凭据，提示「异常活动」「验证失败」查网络环境；
3. 换一个不同地区的节点并用无痕窗口重新登录，排除 Cookie 与插件干扰；
4. 卡在收不到邮件或短信验证码的，转到[验证码收不到的排查](/troubleshooting/verification/)。

## 分场景解决步骤

### 机场官网进不去

1. 在购买确认邮件、客户端订阅备注或机场官方频道里查找备用域名；
2. 忘记密码用注册邮箱重置，重置邮件记得翻垃圾箱；
3. 官网与节点长时间同时失联且没有任何公告，需要警惕服务商跑路的可能，识别方法见[假机场与跑路的识别](/security/fake-airport/)。

### 海外账号被拒

1. 固定使用单一节点登录，避免会话中途换出口；
2. 验证码空白时确认浏览器流量确实经过代理，并暂时停用广告拦截类插件；
3. Google 系服务对登录环境较敏感，注册与找回的注意事项见 [Google 服务使用指南](/software/google/)；
4. 登录成功后尽快开启两步验证，降低异常登录带来的锁定风险，做法见[账号安全防护](/security/account-safety/)。

## 如何判断是不是机场线路的问题

同一节点上多个不同的海外服务都触发验证或拒绝登录，而换节点后立刻正常——指向该节点 IP 信誉不佳；所有节点、所有服务都频繁风控，说明整个 IP 池质量有限，属于机场侧问题，可对照[综合推荐榜单](/airport/recommend/)评估更换。机场官网自身长期无备用域名、故障无公告，同样是服务质量的信号。

## FAQ

**机场官网打不开，是不是跑路了？**

不一定。域名被墙是更常见的原因，此时节点通常还能用。判断依据是节点是否同时失效、官方渠道是否还有更新；持续数日两者皆无，跑路的可能性才明显上升。

**为什么换个节点就能登录了？**

服务方的风控会综合评估出口 IP 的历史行为。原节点 IP 可能因共享用户过多被标记，换到负载低、信誉好的 IP 后评分不同，验证强度随之下降。

**人机验证做完一个又弹一个，怎么办？**

反复出现人机验证通常与 IP 信誉有关。换节点、换无痕窗口、放慢操作节奏都有帮助；同一 IP 短时间多次失败会让验证越来越频繁，不建议硬刷。

**输入的密码明明正确却提示错误？**

先核对当前打开的域名是否为官方地址——仿冒面板会原样收下账号密码再提示错误。从官方渠道重新进入，并尽快修改密码。
