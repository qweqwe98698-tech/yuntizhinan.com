# 订阅导入失败怎么办？先验证链接本身，再查客户端

别急着在客户端里反复重试——把订阅链接复制到浏览器直接打开：能看到一大段配置文本，说明链接有效，问题在客户端一侧；打不开，则先解决链接失效或域名被墙。

## 故障表现

- 新导入订阅时提示无效链接、404 或请求超时；
- 老订阅手动更新失败，报网络错误或解析错误；
- 显示导入成功，但节点列表是空的，或内容是乱码；
- 同一条链接在 A 客户端能用、B 客户端不识别。

## 最常见原因

1. **链接已失效**。在面板里重置过订阅、套餐到期、机场整体更换订阅域名，旧链接都会作废。
2. **订阅域名被墙**。机场常把官网与订阅放在不同域名下，订阅域名被封后直连拿不到配置，表现为超时或连接被重置。
3. **格式不兼容**。Clash 系要 YAML，v2rayN 等常用 Base64 通用格式，sing-box 用 JSON——面板通常提供多个入口或带参数的链接，复制错了就会解析失败。
4. **User-Agent 限制**。一些机场根据请求的 UA 返回对应格式，或拦截来历不明的 UA；小众客户端、下载工具的 UA 可能拿到错误内容。
5. **客户端更新方式设置**。「通过代理更新订阅」开关与当前网络不匹配：代理没在跑却勾了走代理，或域名被墙却选择了直连。

## 快速判断方法

按浏览器打开订阅链接的结果分流：

| 浏览器里的结果 | 结论与下一步 |
| --- | --- |
| 超时或连接被重置 | 开着代理再试，能打开说明订阅域名被墙；仍不行，去面板重新复制或重置链接 |
| 显示到期、流量超限的提示 | 账号状态问题，续费或等流量重置后再更新 |
| 一大段 YAML/Base64 文本 | 链接正常，回头检查客户端的格式选择与 UA |
| 404 或参数错误 | 链接复制不完整或已被重置，回面板取最新链接 |

进不了面板拿新链接的，先按[机场面板登录问题](/troubleshooting/login/)找回入口。

## 「更新订阅需要代理」的死循环怎么破

订阅域名被墙时会出现经典悖论：更新订阅需要先有代理，而代理配置又来自订阅。可行的破法从易到难：

1. 客户端里若还有能连上的旧节点，先连上它并开启「通过代理更新订阅」，再执行更新；
2. 试试机场提供的备用订阅域名，常见于公告或购买邮件；
3. 让另一台有可用代理的设备下载配置文件，再传到本机手动导入；
4. 平时养成习惯：在订阅可用时导出一份本地配置备份，关键时刻能顶上。

## 分客户端解决步骤

### Clash 系（Windows、macOS、Android）

复制面板里标注为 Clash 的链接；更新失败时把「使用系统代理/内核代理更新」的开关各试一次。Clash Verge 的导入入口与常见报错见 [Clash Verge 教程](/tutorials/windows/clash-verge/)，Android 端参考 [Clash Meta 教程](/tutorials/android/clash-meta/)。

### Shadowrocket（iOS）

添加订阅时选通用或 Shadowrocket 专用链接，首次添加建议先手动更新一次确认可用，详见 [Shadowrocket 教程](/tutorials/iphone/shadowrocket/)。

### 其他客户端

sing-box、Quantumult 等对格式要求各不相同，优先使用面板为该客户端准备的专用链接；各平台客户端的配置方法在[教程总览](/tutorials/)里按系统整理。

## 如何判断是不是机场线路的问题

换了网络、开了代理、用了备用域名，浏览器里依旧拿不到配置，且链接重置后仍然如此——问题基本在机场侧，等待公告或联系客服。反之，浏览器能取到配置文本而客户端就是导不进去，那是本地格式或软件问题。订阅域名频繁被墙又长期不提供备用地址的服务商，稳定性值得重新评估，可参考[对 Clash 适配较好的机场](/airport/clash/)。

## FAQ

**订阅链接被别人拿到会怎样？**

对方可以直接使用你的节点并消耗流量。发现流量异常消耗时，第一时间到面板重置订阅链接，旧链接随即作废。

**导入成功但节点列表是空的？**

多为格式入口复制错误，比如把仅含规则的链接当成了节点订阅；回面板换一个格式入口重新复制，并核对链接参数是否完整。

**需要每天手动更新订阅吗？**

不需要。多数客户端支持设定自动更新间隔；机场更换节点或 IP 后，更新一次订阅即可拿到最新列表。

**更新订阅能解决节点全部超时吗？**

如果超时是因为机场换了入口 IP，更新订阅确实有效；但订阅过期、本地网络阻断等原因不在此列，完整排查见[节点全部超时](/troubleshooting/timeout/)。
