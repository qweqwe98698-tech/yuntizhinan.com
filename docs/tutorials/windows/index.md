# Windows 平台客户端选择与配置

在 Windows 上配置代理，主流方案就两条路线：Clash Verge（Rev）和 v2rayN。两者都免费开源、都支持订阅导入，但设计思路完全不同，选错了会多走不少弯路。这一页帮你在两分钟内做出选择。

## 两条路线的核心差异

| 对比项 | Clash Verge（Rev） | v2rayN |
| --- | --- | --- |
| 定位 | 图形化规则分流 | 轻量多协议工具箱 |
| 订阅格式 | Clash / Mihomo 配置 | 通用节点链接与多种格式 |
| 分流方式 | 内置规则引擎，自动分流 | 路由规则需自行选择模式 |
| TUN 模式 | 支持，可接管全部流量 | 依赖内核能力，配置门槛更高 |
| 适合人群 | 想开箱即用、不折腾的用户 | 喜欢手动控制细节的用户 |

一句话结论：机场给的订阅链接如果是 Clash 格式（绝大多数都是），直接选 Clash Verge；如果你手上主要是单节点分享链接，或者希望软件尽量小巧、协议覆盖尽量全，选 v2rayN。

## 教程入口

- [Clash Verge（Rev）入门教程](/tutorials/windows/clash-verge/)：从获取安装、导入订阅讲到系统代理与 TUN 模式的区别，附常见报错处理，推荐新手从这篇开始。
- [v2rayN 使用教程](/tutorials/windows/v2rayn/)：涵盖 .NET 运行库准备、订阅分组管理、节点测速切换与路由规则简介。

两款软件可以同时安装，但同一时间只运行一个，否则会互相抢占系统代理设置。还没有订阅的读者，建议先看[兼容 Clash 订阅的机场怎么选](/airport/clash/)，再回来配置客户端。

## 配置后遇到问题

最常见的情况是客户端显示已连接、节点延迟正常，但浏览器就是打不开网页。这类问题九成出在系统代理没有生效或分流规则误判，对照[Clash 显示已连接但无法上网的排查步骤](/troubleshooting/timeout/clash-no-network/)逐项检查即可。其他症状（订阅导入失败、速度异常等）可在[故障排查中心](/troubleshooting/)按症状定位。
