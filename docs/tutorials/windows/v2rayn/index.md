# v2rayN 导入订阅与切换节点全流程

先说清楚这篇教程适合谁：

- 你的机场提供 v2ray/通用格式订阅，或你手上有单节点分享链接；
- 你希望客户端轻量、协议支持全（VMess、VLESS、Shadowsocks、Trojan、Hysteria2 等）；
- 你不介意手动选择路由模式，换取更细的控制粒度。

如果以上都不是，你的订阅是标准 Clash 格式且只想开箱即用，[Clash Verge 教程](/tutorials/windows/clash-verge/)是更省心的选择。确认继续后，按下面的顺序操作。

## 安装要求与获取方式

v2rayN 是基于 .NET 开发的开源软件，官方发布渠道是 GitHub 上 2dust/v2rayN 项目的 Releases 页面，请通过 GitHub 站内搜索进入，不要从第三方下载站获取。

Releases 页面通常提供多个压缩包：带内核的完整包（文件名含 with-core 之类标识）和不带内核的精简包。**新手一律选带内核的 Windows 64 位完整包**，解压到任意非系统目录即可运行，无需安装。

首次启动如果提示缺少 .NET 桌面运行库，按提示前往微软官网安装对应版本的运行库后再启动。这是正常依赖，不是软件损坏。

## 添加订阅分组与更新

v2rayN 用「订阅分组」管理机场：一个机场对应一个分组，互不干扰。

1. 打开订阅分组设置，新建一个分组，备注填机场名称，地址栏粘贴订阅链接，保存。
2. 回到主界面执行「更新订阅」，片刻后节点列表中会出现该分组的全部节点。
3. 换用多个机场时重复上述步骤即可，节点列表可按分组筛选查看。

日常使用建议每隔几天手动更新一次订阅，机场调整节点后不更新会出现大面积连接失败。更新后列表为空或报错的处理见下文常见问题，更完整的流程在[订阅导入失败排查](/troubleshooting/login/subscription-import-failed/)。

## 节点测速与切换

导入后不要凭感觉挑节点，先测速：在节点列表全选后执行「真连接延迟测试」，它模拟真实访问外网的过程，比单纯 ping 更能反映实际可用性。测试结果中：

- 延迟几十到两百毫秒属于正常区间，数值越低越好；
- 显示超时的节点当前不可用，跳过即可；
- 延迟正常但实际使用卡顿，可能是丢包问题，参考[丢包与延迟诊断](/troubleshooting/speed/packet-loss-diagnosis/)进一步定位。

选中延迟合适的节点，将其设为活动节点即完成切换，托盘图标状态会同步变化。

## 系统代理模式说明

v2rayN 托盘菜单提供几种系统代理状态，含义如下：

- **清除系统代理**：不接管系统流量，仅监听本地端口，适合只给指定软件手动配代理的场景；
- **自动配置系统代理**：将 v2rayN 设为系统代理，浏览器等常规软件自动走代理，是日常推荐状态；
- **不改变系统代理**：保持系统现状，由用户自行管理。

记住一条原则：退出 v2rayN 前确认系统代理已清除或恢复，否则关闭软件后浏览器会因为找不到代理而无法上网。

## 路由规则简介

路由决定哪些流量走代理。v2rayN 内置了几套常用规则集，典型的是「绕过大陆」：国内网站直连、其余走代理，日常保持这一档即可。「全局」则让所有流量走代理，仅排查问题时短用。不同协议节点在路由层面的行为一致，协议本身的差异（加密方式、抗封锁能力）可读 [VMess 与 VLESS 协议详解](/protocols/vmess-vless/)与[协议知识总览](/protocols/)。

## 常见问题

**内核缺失**：启动节点时报错找不到内核或核心文件，多半是下载了精简包，或杀毒软件删除了内核。解决办法：重新获取带内核的完整包，并将 v2rayN 目录加入杀毒软件白名单。

**订阅为空**：更新订阅成功但列表没有节点，最常见原因是订阅链接为 Clash 专用格式，v2rayN 无法解析。回机场用户面板换取通用/v2ray 格式的订阅链接；机场若只提供 Clash 格式，改用 Clash Verge 更合适。选购阶段就想避开格式问题，可参考[机场推荐总览](/airport/recommend/)。

## FAQ

**问：v2rayN 和 v2ray 是一回事吗？**
不是。v2ray（及其继任 Xray）是命令行内核，v2rayN 是调用这些内核的 Windows 图形界面，普通用户装 v2rayN 即可。

**问：可以和 Clash Verge 同时运行吗？**
不建议。两者会争抢系统代理设置和端口，同一时间只运行一个。

**问：升级新版本怎么操作？**
从官方 Releases 获取新版压缩包，覆盖解压到原目录（或解压到新目录后复制原目录的配置文件），节点与订阅设置会保留。

**问：手机上有对应方案吗？**
Android 平台同作者的客户端见 [v2rayNG 教程](/tutorials/android/v2rayng/)，操作逻辑高度相似。
