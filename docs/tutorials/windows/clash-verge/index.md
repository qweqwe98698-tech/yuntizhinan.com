# Clash Verge Rev 新手完整指南

Clash Verge Rev 是目前 Windows 上最受欢迎的图形化代理客户端：内核基于 Mihomo（Clash Meta 的延续项目），界面基于原 Clash Verge 由社区接手维护，因此常被简称为 Verge 或 Verge Rev。它的核心优势是「导入订阅即用」——分流规则由订阅配置提供，你几乎不需要手写任何配置。本文按首次使用的完整流程展开，预计十五分钟可以完成配置。

## 获取与安装

Clash Verge Rev 的唯一官方发布渠道是 GitHub 上 clash-verge-rev 项目的 Releases 页面，请在 GitHub 站内搜索项目名进入，认准仓库主页的发布列表。搜索引擎里排名靠前的「官网」下载站不少是第三方镜像甚至捆绑了恶意程序的假冒页面，辨别方法见[假冒网站与钓鱼陷阱识别](/security/fake-airport/)。

下载时选择 Windows 的 x64 安装包（绝大多数电脑适用）。安装过程中 Windows 可能弹出安全提示，属于未签名开源软件的正常现象，确认来源是官方 Releases 即可继续。安装完成后首次启动，程序会驻留在任务栏托盘区，主界面关闭不等于退出。

## 导入机场订阅

导入前你需要一条机场提供的订阅链接。还没有订阅的读者可以先看[兼容 Clash 的机场推荐](/airport/clash/)了解挑选思路。拿到链接后有两种导入方式：

**方式一：URL 导入（推荐）。** 在客户端的订阅/配置页面选择新建，类型选远程（URL），粘贴订阅链接后确认导入。成功后列表中会出现一个带流量信息的配置卡片，点击选中即为启用。

**方式二：剪贴板导入。** 先在浏览器或机场网站复制订阅链接，回到订阅页面选择「从剪贴板导入」（部分版本叫粘贴导入），客户端会自动读取剪贴板中的链接完成添加。两种方式效果相同，剪贴板方式少一步粘贴操作。

如果导入时报错或一直转圈，通常是链接不完整、订阅过期或网络被拦截，按[订阅导入失败的完整排查](/troubleshooting/login/subscription-import-failed/)逐项处理。

## 看懂界面的五个概念

- **配置文件（Profile）**：一条订阅对应一个配置文件，里面包含全部节点和分流规则。多个机场就有多个配置文件，同一时间只能启用一个。
- **代理组**：节点的分组视图。常见的有「自动选择」（按延迟自动挑节点）、「手动选择」以及按地区、按用途划分的组，在代理页面点选即可切换节点。
- **规则**：决定哪些流量走代理、哪些直连的分流清单，由订阅提供，日常保持「规则模式」即可，国内网站不会被绕路。
- **全局**：所有流量都走当前选中节点，适合排查分流问题时短暂使用。
- **直连**：所有流量都不走代理，等价于临时关闭。

各协议节点（Shadowsocks、VMess、Trojan 等）在 Clash 系客户端里的使用方式完全一致，想了解差异可读[代理协议知识总览](/protocols/)。

## 系统代理与 TUN 模式

这是新手最容易混淆的一组开关，两者都在设置页面：

**系统代理**是标准玩法：客户端把自己注册为 Windows 的系统代理，浏览器和大部分常见软件会自动走代理。优点是轻量稳定，缺点是部分软件（一些游戏、命令行程序）不读系统代理设置，流量会漏掉。

**TUN 模式**通过虚拟网卡在系统层接管全部流量，不遵守系统代理的软件也会被代理。首次开启需要按客户端提示安装服务或授予管理员权限。日常建议只开系统代理；确有全局接管需求（如命令行开发、游戏加速）再启用 TUN，两者不要同时依赖。

## 订阅更新与自动更新

机场会不定期调整节点，本地配置需要更新才能同步。手动更新在订阅卡片上选择更新即可；建议同时在订阅设置里将自动更新间隔设为 12 或 24 小时，避免因节点失效误以为服务出了问题。更新失败时先试关闭代理再更新（用直连网络拉取），仍失败则多为订阅链接本身的问题。

## 常见报错处理

- **端口占用**：启动时提示端口被占用，多为电脑上另一个代理软件（如 v2rayN）未退出，或其他程序占了同一端口。退出冲突软件，或在设置中更换混合代理端口即可。
- **内核启动失败**：常见原因是被杀毒软件或 Windows 安全中心误删了内核文件。将安装目录加入白名单后重装，或在设置中重新安装内核。
- **订阅一直更新失败**：参考上文导入部分，按[订阅导入失败排查](/troubleshooting/login/subscription-import-failed/)处理。
- **连上了但打不开网页**：节点延迟正常却无法上网，按[Clash 无网络问题排查](/troubleshooting/timeout/clash-no-network/)检查系统代理与规则设置。

## FAQ

**问：Clash Verge 和 Clash Verge Rev 是什么关系？**
原 Clash Verge 已停止维护，Rev 是社区延续的活跃分支，功能与界面一脉相承。现在获取到的新版本均为 Rev，教程通用。

**问：需要开机自启吗？**
建议开启。在设置中打开开机自启后，客户端随系统静默启动并自动恢复上次的代理状态，避免重启后忘开代理。

**问：我的订阅是 v2ray 格式，能用吗？**
Clash Verge 需要 Clash/Mihomo 格式订阅。多数机场同时提供两种格式，在用户面板切换即可；如果只有单节点分享链接，改用 [v2rayN 教程](/tutorials/windows/v2rayn/)的方案更合适。

**问：Mac 上有对应的客户端吗？**
有，思路一致的图形客户端可参考 [macOS 平台的 Mihomo Party 教程](/tutorials/macos/mihomo-party/)。
