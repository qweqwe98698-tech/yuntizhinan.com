# 路由器上跑代理，先想清楚再动手

先说结论：软路由是体验上限最高、也最容易把家里网络搞瘫的方案。它值得折腾，但不适合作为你的第一个代理方案——动路由器之前，你最好已经在电脑或手机上把客户端用明白了，起点可以是[客户端教程总览](/tutorials/)。

## 适合谁

- 家里设备多，不想每台单独装客户端、逐台导入订阅；
- 有电视盒子、游戏主机、智能家居这类装不了代理客户端的设备；
- 愿意为「全屋无感代理」投入学习成本，也接受偶尔停下来排障。

## 风险提示

路由器是全屋网络的咽喉。客户端配置错了只影响一台设备，路由器配置错了，全家的网会一起断——DNS 配置冲突、透明代理规则写错、插件与固件不兼容，都可能造成整户断网。刷第三方固件本身还有变砖风险，也可能失去保修。两条降低风险的建议：

- 用一台闲置设备做旁路由或二级路由先行试验，验证稳定后再考虑接管主网络；
- 动手前备份路由器配置，并确认自己会通过网线直连进入管理后台恢复直连。

## 教程入口

- [OpenWrt 代理配置思路](/tutorials/router/openwrt/)：不绑定具体插件，讲清硬件门槛、通用配置流程、订阅导入与策略组、DNS 防污染要点、大陆直连分流建议，以及出问题时的回退方案，建议动手前通读一遍。

订阅本身的质量同样关键，路由器插件普遍基于 Clash 系内核与订阅格式，挑选思路见[兼容 Clash 订阅的机场怎么选](/airport/clash/)。

## 配置后最常见的坑

软路由的故障十有八九落在 DNS 上：节点明明能连通，网页却打不开或被解析到错误地址，这类问题的判断与处理见 [DNS 问题排查](/troubleshooting/dns/)。若是整体断流、超时，先按[连接超时排查](/troubleshooting/timeout/)恢复网络，再回头定位插件配置的问题。
