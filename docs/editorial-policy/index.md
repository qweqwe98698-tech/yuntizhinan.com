# 云梯指南的编辑规范

这份政策约束本站发布的每一篇内容——从[软件百科](/software/)到[机场评测](/reviews/)，无一例外。它回答三个问题：我们写什么、按什么标准写、什么坚决不写。

## 选题原则

解决真实问题优先。选题来自读者实际遇到的困惑：某个客户端怎么配、某类故障怎么排查、某家服务商值不值得买。我们不做纯粹追热点的内容，也不为覆盖关键词而制造没有信息增量的页面。

## 内容标准

- **唯一性**：每篇文章拥有全站唯一的标题与描述，同一问题不换皮重发、不拆分成多篇雷同内容；
- **时间可查**：所有文章注明发布时间与最近更新时间，时效性内容以更新时间为准；
- **原创**：不复制、不洗稿改写他站内容。引用外部数据时注明来源；
- **可验证**：涉及测试数据的内容遵循[测试方法](/about/methodology/)中的流程，测试环境在文内公示。

## 禁止性规范

以下行为在本站被明确禁止：

- **不编造测速与体验**：没有实际测试就没有数据，未完成测试的品牌标注「待实测」；
- **不编造用户评价**：不虚构「网友反馈」「用户口碑」为结论背书；
- **不做虚假五星评分**：评分只出现在完成标准流程的评测中，且与测试结果对应；
- **不使用绝对化表述**：「永不跑路」「绝对稳定」这类断言不会出现在本站。我们改用可验证的相对表述，例如「运营时间较长」「当前测试稳定」「风险相对较低」。

## 商业内容与编辑内容的隔离

本站通过推广链接获得佣金，但商业关系与编辑结论之间设有明确隔离：

- 推广合作不影响评分与结论，负面结论照常发布；
- 品牌方无权预审或修改评测内容；
- 推广链接的使用位置与标注方式，详见[推广关系披露](/affiliate-disclosure/)。

## 更新与下线机制

境外网络服务变化很快，价格、政策、节点状况都可能过期。对此我们的处理方式是：

- 仍有价值但数据过期的内容，标注数据日期并安排复测；
- 已彻底失效的内容，下线并设置 301 跳转到替代页面，避免读者落在错误信息上；
- 读者发现的错误按[纠错政策](/correction-policy/)处理，重大修正在文内留有记录。
