# 关于本站的推广链接

透明是信任的前提。本页说明云梯指南在哪些位置使用推广链接、它如何运作、对你意味着什么，以及我们为隔离商业利益与评测结论所做的约束。

## 什么是推广链接

推广链接（affiliate link）是带有本站标识的跳转链接。当你通过它访问某家机场服务商并完成购买时，服务商会向本站支付一笔佣金。这是本站维持运营的主要收入来源，也是许多独立评测网站的通行模式。

## 我们在哪些位置使用

推广链接只出现在以下位置，不会伪装成普通内容链接：

- [机场知识](/airport/)栏目中的推荐页；
- [机场评测](/reviews/)文章中指向被评测品牌的购买入口；
- 部分文章末尾的推荐卡片；
- 移动端底部的推荐提示条（可手动关闭）。

## 对你的影响

通过推广链接购买**不会增加你的任何费用**——价格与直接访问官网完全一致，佣金由服务商从其收入中支付。你也完全可以不经推广链接、自行搜索官网下单，这不影响你使用本站的任何内容。

## 披露原则

- 含有推广链接的文章会在显著位置显示披露框，提示该文包含推广链接；
- 推广链接统一添加 rel="sponsored nofollow" 属性，向搜索引擎明确标注其商业性质；
- 我们不使用弹窗、倒计时等施压手段促成点击。

## 佣金不影响评测结论

这是本站最核心的承诺：**评测怎么写，与佣金多少无关**。

- 所有评测遵循公开的[测试方法](/about/methodology/)，数据来自自费购买套餐的实测；
- 测试结果不佳的品牌，负面结论照常发布，即使它提供佣金；
- 未与本站建立推广合作的品牌，同样可能被纳入评测——选题以读者关注度为准，而非合作关系；
- 品牌方无权预审或修改评测内容，相关规范详见[编辑政策](/editorial-policy/)。

如果你认为某篇内容的商业标注不清晰，或披露框有遗漏，欢迎按[纠错政策](/correction-policy/)向我们反馈。
