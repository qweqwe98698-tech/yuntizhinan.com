# 我们如何测试一家机场

一份可信的评测，前提是方法公开、过程可复现。本页完整公开云梯指南[机场评测](/reviews/)所使用的标准流程与指标——每一篇标注「已实测」的评测都走完了下述全部环节，缺一项就不出结论。

## 测试环境记录

每次测试开始前，我们先记录并在评测文内公示以下信息，读者可据此判断数据对自己的参考价值：

- 测试日期与时段
- 测试地区与本地运营商（电信 / 联通 / 移动）
- 测试设备与操作系统
- 所用客户端及版本
- 实际购买的套餐档位

我们使用自费购买的普通套餐进行测试，不使用服务商提供的测试账号。

## 测试项目

### 连接质量

- **节点延迟与丢包**：对主要地区节点分别测量延迟与丢包率，多次采样取分布而非单次峰值；
- **晚高峰测速**：在 20:00–23:00 的拥堵时段测速，与平峰数据对照，避免只展示理想成绩；
- **WebSocket 长连接稳定性**：持续保持长连接观察断线频率，这直接影响网页应用与即时通讯的体验；
- **大文件下载稳定性**：进行长时间大文件下载，观察速度波动与中断情况。

### 服务可用性

逐项验证 ChatGPT、Telegram、Netflix、YouTube 的实际可用性与解锁情况，记录具体节点与结果，不以「基本都能用」之类的模糊表述代替。

### 售后体验

- **客服响应**：以普通用户身份提交工单或咨询，记录响应速度与解决质量；
- **退款规则**：核对官方退款条款，并在条件允许时实际验证执行情况。

## 「待实测」标注制度

未完成上述标准流程的品牌，页面一律显示「待实测」徽章，**不显示评分，也不给出解锁结论**。我们宁可标注待实测，也不基于二手信息或厂商宣传写出看似完整的评测。这一制度同样受[编辑政策](/editorial-policy/)中禁止编造数据条款的约束。

## 复测周期与数据时效

机场的节点质量与解锁状态会随时间变化。已发布的评测按周期安排复测，数据更新后同步修改「更新于」时间；超过时效仍未复测的内容会明确标注数据日期，供读者自行折价参考。

## 评测独立性声明

测试所用账号由本站自费购买，评测结论不受商业合作影响，负面结果照常发布。部分链接为推广链接，详见[推广关系披露](/affiliate-disclosure/)；关于机场的基础知识与选购思路，可参考[机场知识](/airport/)栏目。
