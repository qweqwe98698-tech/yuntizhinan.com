# 关于云梯指南

云梯指南（yuntizhinan.com）是一个面向中文用户的境外网络服务知识库。我们把散落在论坛、群聊和过期博客里的经验整理成体系化的内容：既解释海外软件与服务本身，也解决访问它们时遇到的实际问题，并在此基础上提供经过实测的机场推荐与评测。

## 五层内容结构

本站内容按「从认识到解决」的顺序分为五层，层与层之间相互引用、逐级递进：

1. **软件百科**——ChatGPT、Telegram、Netflix 等海外软件与服务的介绍、注册与使用要点；
2. **客户端教程**——Clash、Shadowrocket 等代理客户端的配置与订阅导入步骤；
3. **故障排查**——连不上、速度慢、节点失效等常见问题的定位与解决；
4. **网络需求**——不同使用场景（流媒体解锁、跨境办公、学术访问等）对网络服务的具体要求；
5. **机场推荐评测**——基于标准流程实测后给出的服务商横向对比与结论。

## 谁在写这些内容

本站内容由**云梯指南编辑部**撰写与维护。我们不署个人笔名、不制造人设，所有页面对结论负责的是编辑部整体，修正记录与更新时间公开可查。

## 内容原则

- **真实实测**：测速数据、解锁结果、客服体验均来自我们自己的测试，测试环境在文中注明。方法细节见[测试方法](/about/methodology/)。
- **明确标注待实测**：尚未完成标准测试流程的品牌，一律标注「待实测」，不显示评分与解锁结论。
- **独立第三方**：本站与任何机场服务商不存在隶属或投资关系，不接受品牌方修改评测结论的要求，负面结论照常发布。完整规范见[编辑政策](/editorial-policy/)。

## 如何使用本站

根据你当前的需求，从以下入口开始通常最快：

- 想了解某个海外软件或服务，去[软件百科](/software/)；
- 客户端不会配、订阅不会导入，看[客户端教程](/tutorials/)；
- 已经在用但出了问题，查[故障排查](/troubleshooting/)；
- 想系统了解机场是什么、如何挑选，读[机场知识](/airport/)；
- 准备直接选购，参考[机场评测](/reviews/)中已完成实测的品牌。

如果不确定从哪开始，可以先回[首页](/)浏览最新更新的内容。
